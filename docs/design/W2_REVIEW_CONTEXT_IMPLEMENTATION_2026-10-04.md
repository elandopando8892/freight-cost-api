Binding estricto: org/base/versión, catálogo/perfil exactos, fingerprint de versión fuente, no comercial/no adopción/no modificación del perfil. Sólo un binding, DRAFT no activo/base DRAFT/CROSS_BORDER; sin fallback a otra base, a THROUGH_TRACTOR o a catálogo libre. Registro de propuestas de revisión versionado separado; no mezcla ni reinicio de recibos históricos. Cambios de binding, fuente o contexto invalidan lectura/guardado. API conserva ADMIN writer y locks/receipts actuales.
